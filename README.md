# 🛍️ Snitch – Buy & Sell Marketplace

Snitch is a web-based marketplace that allows users to act as both buyers and sellers on a single platform. Users can explore products, purchase items, and sell their own products through a user-friendly interface.

## ✨ Features

- 🛒 **Buyer:** Browse products and explore available items.
- 🏷️ **Seller:** List and sell products on the platform.
- 👤 **User Authentication:** Access the platform through user accounts.
- 🔄 **Dual Role:** Use the platform as both a buyer and a seller.
- 📱 **Responsive UI:** Enjoy a smooth experience across different devices.
- 🗄️ **Database Integration:** Store and manage application data using MySQL.

## 🛠️ Tech Stack

- **Frontend:** React.js, HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MySQL
- **Tools:** Git, GitHub, npm

## ⚙️ Installation & Setup

**1. Clone the repository**

```bash
git clone https://github.com/tashumalviya/Snitch.git
cd Snitch
```

**2. Install dependencies**

Navigate to the frontend and backend directories and run:

```bash
npm install
```

**3. Configure the database**

- Start your local MySQL server.
- Create the required database.
- Configure the database credentials in the backend `.env` file.
- Set up the required database tables.

**4. Start the application**

Run the frontend and backend using the scripts provided in their respective `package.json` files.

## 🎯 Project Objective

The goal of Snitch is to provide a convenient platform where users can buy and sell products in one place, making online shopping and product selling easier.
